# ADR 0002 · 模型接入与调度责任

**状态** 拟议 · 2026-11-27

## 决策建议

将 Magpie 接为可选推理与遥测网关。网关处理受控资源池内的协议转换与单次请求路由。QuotaFlow 选择任务尝试的 Agent、资源池和可用账户范围，持有并核销任务级资源租约，负责写工作区中的跨 Agent 交接。Codex 和 OpenCode 保留原生接入，后续扩展直接 API 和本地模型。

## 关键约束

- 一次任务允许经过多个尝试，尝试与网关请求使用可关联标识。记录请求模型、允许范围、实际模型与账户证据，网关组中的回退也必须满足任务权限、额度与预算策略。关键路径只允许可约束且可审计的组成员或固定模型通道。
- 推理、遥测、管理权限分别配置。用最小权限读取可见字段，控制面负责保存和脱敏。账户、窗口、归属或成本未知时记录 `UNKNOWN`，并按批准策略等待或使用可证实符合约束的通道。
- 原生接入使用供应商支持的授权方式。测试证明订阅与付费资源的边界后才纳入自动调度。网关不可用时保留已批准的原生或本地路径，关键审查依旧执行能力门禁。

## 定版证据

核验实际版本、运行模式、认证、健康与额度窗口、历史、请求级用量与费用、路由组、回退事件和归属。对不可观测字段逐项记录缺失原因，验证在网关不可用时仍可完成独立交接。以[源码初筛](../RESEARCH.md)和可重跑的 Phase 0 报告更新 ADR。
