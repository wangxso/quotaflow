# ADR 0002 · 模型接入与调度责任

**状态** 暂定建议；Phase 0 门禁未通过 · 2026-11-27

## 决策

建议将 Magpie 接为可选推理与遥测网关。隔离实例已验证路由组回退和本地模型遥测；生产接入前仍需核对实际凭据范围、商业账户的用量／费用归属。QuotaFlow 的 Agent 选择、资源租约和工作区交接由控制面负责。Codex 和 OpenCode 保留原生接入，后续扩展直接 API 和本地模型。该建议尚未达到 Phase 0 阶段门禁。

## 关键约束

- 一次任务允许经过多个尝试，尝试与网关请求使用可关联标识。记录请求模型、允许范围、实际模型与账户证据，网关组中的回退也必须满足任务权限、额度与预算策略。关键路径只允许可约束且可审计的组成员或固定模型通道。
- 推理、遥测、管理权限分别配置。用最小权限读取可见字段，控制面负责保存和脱敏。账户、窗口、归属或成本未知时记录 `UNKNOWN`，并按批准策略等待或使用可证实符合约束的通道。
- 原生接入使用供应商支持的授权方式。测试证明订阅与付费资源的边界后才纳入自动调度。网关不可用时保留已批准的原生或本地路径，关键审查依旧执行能力门禁。

## 证据与边界

便携 Magpie 实例已验证逻辑资源池、503 回退、实际模型事件和真实本地推理。现有实例的读取接口与 Codex 原生额度分开验证。真实商业账号的账单归属、受限密钥的字段可见范围以及供应商特有错误需要针对实际账号继续核对。[Phase 0 报告](../PHASE-0.md)
